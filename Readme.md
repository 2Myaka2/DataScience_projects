# Проект спринта 15: поведенческий скоринг
Вы уже знакомы со стоящей в этом проекте задачей и с требованиями заказчика. Кратко напомним о них (возвращайтесь к этому описанию, если забыли ключевые условия).
Вы решаете задачу поведенческого скоринга. Ваша цель — предсказать вероятность того, что клиент банка совершит просрочку платежа по кредиту длительностью от 90 дней. Объект моделирования — это клиент в конкретный месяц, целевая переменная — столбец, содержащий данные о том, будет ли у клиента просрочка от 90 дней в течение ближайших 12 месяцев.
## Требования к решению
Выполните стандартные шаги по подготовке рабочего пространства:
Дайте название тетрадке Jupyter, коротко опишите в ней суть проекта.
Сформулируйте задачу в терминах машинного обучения.
Импортируйте все необходимые библиотеки.
Загрузите датасеты.
Проведите исследовательский анализ данных. Сделайте выводы о выбросах, пропусках, дубликатах и иных особенностях в данных по каждой таблице.
Соберите все источники данных о клиентах в единую таблицу наблюдений. Рекомендации по тому, как корректно объединить данные, указаны в тетрадке Jupyter.
Создайте в итоговой таблице новые признаки, которые помогут модели лучше изучить закономерности в данных. Создайте не менее двух новых признаков.
Проанализируйте баланс классов в целевой переменной. Сделайте выводы о необходимых действиях.
Создайте для моделирования три выборки: обучающую, калибровочную и тестовую.
При разделении данных учтите, что в них заложена временная структура по каждому клиенту, поэтому вам нужен специальный метод создания выборок, учитывающий и деление по группам, и временную структуру — GroupTimeSeriesSplit().
При необходимости проведите категоризацию данных, применив нужный Encoder и использовав пайплайн.
Обучите базовые варианты нескольких моделей с кросс-валидацией на трёх фолдах. Сравните базовые варианты логистической регрессии и случайного леса:
Модели, обученные на исходных данных, в которых доля объектов одного из классов выше, чем другого.
Модели, обученные с применением одного из методов балансировки классов — class_weight, RandomOverSampler, RandomUnderSampler, SMOTE.
Должно получиться сравнение четырёх базовых моделей.
Реализуйте итоговое решение на основе ансамблевой модели Random Forest со стратегией балансировки классов и подбором гиперпараметров. Именно эта модель будет использована как основной инструмент поведенческого скоринга.
Используйте кросс-валидацию на трёх фолдах.
Учитывайте временную структуру данных при обучении Random Forest. Для разделения на фолды обучающих данных используйте GroupTimeSeriesSplit().
Выберите оптимальный метод балансировки классов, ответ обоснуйте.
Подберите гиперпараметры модели с помощью Optuna. Количество гиперпараметров должно быть не менее трёх. Используйте метрику missed defaults rate при подборе гиперпараметров.
Оцените модели по нескольким метрикам:
Approval rate — постарайтесь добиться максимально возможного значения.
Default rate и missed defaults rate — постарайтесь добиться минимально возможных значений.
Для сравнения моделей рассмотрите одну из метрик: accuracy или ROC-AUC.
Проведите калибровку лучшей модели, обученной на полной тренировочной выборке. Постройте график калибровки.
Найдите порог, при котором:
Approval rate не менее 65%;
Default rate не более 2%;
Missed defaults rate не более 4%.
Проверьте модель на тестовой выборке.
Изучите матрицы ошибок модели на калибровочной и тестовой выборках. Сделайте вывод о стабильности метрик на разных выборках. Используйте и технические метрики, и бизнес-метрики.
Зафиксируйте итоговые параметры лучшей модели.
Оцените важность признаков с помощью feature_importances_.
Оформите выводы своего исследования. Напишите общие выводы и рекомендации по дальнейшей работе модели.
Дополнительные инструкции по некоторым из шагов размещены в Jupyter Notebook.
## Рекомендации к выполнению проекта
Старайтесь как можно чаще оборачивать код в понятные и удобные функции, пригодные для повторного использования (то есть для вызова с другими значениями параметров), или создавать циклы для перебора разных решений.
Например, можно написать функцию для обучения базовых моделей с балансировками и без балансировки.
Можно написать цикл для вызова разных моделей. Это поможет работать с пространством признаков, удаляя и добавляя признаки и перезапуская решение.
Автоматизация и оборачивание в функции позволят сделать код короче и снизят вероятность ошибок, поскольку вам нужно будет только изменить конкретные значения параметров, а не создавать ячейки примерно одного содержания многократно.
Используйте возможности оформления Markdown, включая заголовки, чтобы сделать вашу тетрадку Jupyter наглядной и удобной для навигации.
Не забывайте периодически сохранять ваши правки в тетрадке, иначе ваш код может пропасть из-за непредвиденных технических ошибок.
